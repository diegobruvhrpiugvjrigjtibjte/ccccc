RESOURCES — Guides

/ro/resources/guides/

HWTRS se bazează pe o promisiune simplă: criptare locală, transparentă și sub controlul tău. Această pagină explică o parte specifică a platformei, dar urmează aceleași principii peste tot. Fișierele nu părăsesc dispozitivul și nu există conturi, trackere sau servicii ascunse. Folosim AES-256-GCM pentru confidențialitate și integritate și PBKDF2 pentru derivarea cheilor. Rezultatul este un arhivă .hwtrs sigură care poate fi partajată fără expunerea conținutului. Securitatea depinde de parola aleasă și de starea dispozitivului, de aceea recomandăm fraze puternice. Dacă parola se pierde, recuperarea nu este posibilă, deoarece zero-knowledge trebuie să rămână absolut. Această pagină explică și ce protejează sistemul și ce nu protejează. Browserul are limite de memorie și performanță, mai ales cu fișiere mari, iar noi le documentăm. Transparența contează: logica este auditabilă, formatul este clar, iar fluxul este repetabil. HWTRS nu este un cloud și nu înlocuiește un backup; este un instrument de criptare locală. Folosește-l pentru documente, arhive personale sau transferuri sigure și păstrează copii de rezervă. Oferim documentație despre riscuri, bune practici și detalii operaționale. Această pagină face parte dintr-o bază de cunoștințe care construiește încredere. Pentru întrebări, contactează echipa.
