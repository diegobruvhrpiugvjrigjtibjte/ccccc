DOCS — Browser Limits

/es/docs/browser-limits/

HWTRS se basa en una promesa simple: cifrado local, transparente y bajo tu control. Esta página explica una parte concreta de la plataforma, pero sigue los mismos principios en cada área. Los archivos no salen del dispositivo y no hay cuentas, rastreadores ni servicios ocultos. Usamos AES-256-GCM para confidencialidad e integridad, y PBKDF2 para derivar claves fuertes desde la contraseña. El resultado es un archivo .hwtrs seguro que se puede compartir sin exponer el contenido. La seguridad depende de la calidad de la contraseña y del estado del dispositivo, por eso recomendamos frases fuertes. Si se pierde la contraseña, no hay recuperación por diseño, porque el zero-knowledge debe ser absoluto. Esta página también explica qué puede y qué no puede proteger el sistema para evitar falsas expectativas. El navegador tiene límites de memoria y rendimiento, especialmente con archivos grandes, y los documentamos. La transparencia importa: la lógica es auditable, el formato es claro y el flujo es repetible. HWTRS no es un cloud y no sustituye a un backup; es una herramienta de cifrado local. Úsalo para documentos, archivos privados o transferencias seguras, y mantén copias de respaldo. Ofrecemos documentación para entender riesgos, buenas prácticas y detalles operativos. Esta página forma parte de una base de conocimiento para generar confianza real. Si necesitas soporte o tienes preguntas, contacta al equipo para ayuda y divulgación responsable.
