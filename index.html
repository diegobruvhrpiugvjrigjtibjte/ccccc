File Decifrati

Una soluzione completa per la cifratura locale

HWTRS nasce per risolvere un problema semplice: proteggere i file senza affidarsi a server esterni. Tutto avviene nel tuo browser, con una cifratura AES-256-GCM e una derivazione chiave PBKDF2 che rende le password robuste anche contro attacchi offline. Questo significa che i tuoi dati rimangono sul tuo dispositivo e non vengono mai trasmessi verso terze parti, riducendo drasticamente la superficie di rischio.

Il flusso è lineare: scegli i file, imposti una password forte e crei un archivio .hwtrs. In fase di apertura, HWTRS decifra localmente e ti restituisce i file originali, mantenendo i nomi e i formati. Non esistono account, non esiste registrazione e non c’è un database da violare. Questa scelta rende la soluzione più snella e coerente con la filosofia zero-knowledge.

La piattaforma è pensata anche per contesti professionali. Puoi cifrare documenti sensibili, allegati finanziari, file HR, backup di progetti o asset creativi. Il tutto resta sotto il tuo controllo e può essere condiviso in modo sicuro con chi possiede la password, senza dipendere da infrastrutture esterne.

HWTRS è progettata per essere chiara, verificabile e trasparente: la logica è visibile e ispezionabile, così puoi capire come funziona la cifratura e verificare che non ci siano comportamenti nascosti. È una scelta ideale per chi cerca privacy reale e un’esperienza semplice da utilizzare.

Come funziona

HWTRS segue un modello operativo chiaro: prepara i file, cifra localmente, condividi in sicurezza e apri solo con la password. Ecco i 4 passaggi chiave in modo semplice e comprensibile.

1. Seleziona e prepara i file

Aggiungi uno o più file fino a 150MB. HWTRS costruisce una struttura locale con metadati minimi (nome, peso, formato) per ricostruire esattamente il contenuto in fase di apertura. Nessun file lascia mai il tuo dispositivo in questa fase.

2. Imposta una password forte

La password è la chiave di accesso. Con PBKDF2 e 300.000 iterazioni, HWTRS deriva una chiave AES-256-GCM resistente ai tentativi di forza bruta. Più è lunga e complessa, maggiore è la protezione per i tuoi file.

3. Crea l’archivio .hwtrs

I file vengono impacchettati localmente e cifrati con AES-256-GCM. Il risultato è un singolo file .hwtrs che puoi salvare, archiviare o condividere. Non contiene dati in chiaro e non è leggibile senza la password.

4. Apri e recupera i file

Carica l’archivio .hwtrs, inserisci la password e HWTRS ricostruisce i file originali in locale. Puoi scaricarli singolarmente o in ZIP, mantenendo la privacy fino all’ultimo passaggio.

Sicurezza e threat model

HWTRS è progettata per proteggere i tuoi file in scenari reali: archiviazione personale, condivisione sicura tra team, invio di documenti sensibili via email o cloud. La cifratura avviene interamente nel browser usando AES-256-GCM, uno standard moderno e ampiamente adottato. La derivazione della chiave utilizza PBKDF2 con 300.000 iterazioni, riducendo la velocità di tentativi a forza bruta.

Cosa protegge: accesso non autorizzato al contenuto dei file se l’archivio viene intercettato o condiviso. Anche se il file .hwtrs viene copiato, rimane illeggibile senza password. La cifratura è end-to-end locale: non ci sono server, API o database che possano essere compromessi.

Cosa non protegge: se il dispositivo è compromesso (malware, keylogger, estensioni malevole) un attaccante potrebbe leggere i file prima o dopo la cifratura. Inoltre, se la password è debole o viene condivisa, la protezione decade. HWTRS non può mitigare errori umani o rischi al di fuori del browser.

Password dimenticata: la cifratura è irreversibile senza la password corretta. Non esistono backdoor o recuperi. È una scelta voluta per garantire la privacy. Consigliamo di usare un password manager e, se necessario, conservare la password in un luogo sicuro.

Limiti del browser: la cifratura avviene in RAM e può essere influenzata dalle risorse disponibili. File molto grandi o dispositivi con poca memoria possono rallentare l’operazione. L’archivio resta però coerente e verificabile grazie ai controlli di integrità sul payload.

In sintesi, HWTRS è una soluzione robusta per scenari di sicurezza client-side. È pensata per utenti che vogliono controllo completo e trasparenza, accettando che la responsabilità della password resti sempre in mano loro.

Privacy Policy

HWTRS rispetta la tua privacy fin dal design. Non raccogliamo dati personali, non utilizziamo strumenti di tracking e non trasferiamo file verso server esterni. Tutto avviene localmente nel browser dell’utente.

Utilizziamo esclusivamente storage locale (localStorage) per salvare preferenze di interfaccia, come l’ultima tab selezionata o l’accettazione del banner cookie. Non salviamo password, file o metadati sensibili. Non esistono cookie di profilazione o analytics di terze parti.

I file restano sempre sul dispositivo e sono cifrati prima di qualsiasi download. HWTRS non dispone di backend, log o sistemi di raccolta dati. Questo garantisce un approccio zero-knowledge, in cui solo l’utente ha accesso ai contenuti.

Contatto: per richieste, segnalazioni o chiarimenti puoi scrivere a security@hwtrs.example. Risponderemo nel minor tempo possibile.

Questa policy può essere aggiornata in futuro per migliorare la chiarezza o per adattarsi a nuove normative. Qualsiasi modifica sarà pubblicata in questa pagina.

FAQ

Risposte rapide alle domande più comuni.

HWTRS invia i miei file a un server?

No. Tutto avviene localmente nel browser. Nessun file viene caricato.

Cosa succede se dimentico la password?

Non è possibile recuperare l’archivio. La cifratura è irreversibile senza la password.

Qual è l’algoritmo di cifratura?

AES-256-GCM con chiave derivata tramite PBKDF2.

Qual è il limite massimo di dimensione?

150MB per archivio, con gestione ottimizzata per file multipli.

Posso usare HWTRS su mobile?

Sì, ma le prestazioni dipendono dalla RAM disponibile sul dispositivo.

I file .hwtrs sono compatibili in futuro?

Sì, la versione è inclusa nel formato e gestiamo compatibilità base.

Posso condividere l’archivio via email?

Sì, l’archivio è cifrato. Condividi la password solo su canali sicuri.

Serve installare qualcosa?

No, funziona direttamente nel browser con Web Crypto API.

Posso verificare il codice?

Sì, l’intera logica è visibile e ispezionabile.

HWTRS usa cookie di tracciamento?

No, solo cookie tecnici e localStorage per preferenze UI.

Come posso contattarvi?

Scrivi a security@hwtrs.example per supporto o richieste.

È adatto per uso aziendale?

Sì, soprattutto per cifrare dati sensibili in modo autonomo.
