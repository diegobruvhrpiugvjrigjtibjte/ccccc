Privacy Policy di FileCheck

Ultimo aggiornamento: 2024-01-01

FileCheck è un'applicazione local-first progettata per analizzare file direttamente sul dispositivo dell'utente. Non esistono server remoti, database cloud o sistemi di tracciamento associati all'applicazione.

1. Dati trattati

FileCheck non raccoglie né trasmette file, contenuti o dati personali verso server esterni. Tutta l'elaborazione avviene nel browser dell'utente tramite API locali (File API, Web Crypto, Web Workers, IndexedDB).

2. Cookie e storage locali

L'app utilizza esclusivamente storage tecnici locali (localStorage, sessionStorage e IndexedDB) per memorizzare preferenze, cronologia delle analisi e stato delle funzioni avanzate. Nessun cookie di profilazione o pubblicità viene utilizzato.

3. Finalità e base giuridica

Le informazioni locali vengono salvate esclusivamente per migliorare l'esperienza d'uso e sono gestite direttamente dall'utente. La base giuridica è il legittimo interesse dell'utente a utilizzare l'applicazione in modalità locale.

4. Diritti dell'utente

L'utente può eliminare in qualsiasi momento tutte le informazioni locali cancellando i dati del browser o utilizzando le funzioni di reset nell'app. Non essendoci dati remoti, non esistono archivi centralizzati su cui esercitare richieste di accesso o cancellazione.

5. Sicurezza

FileCheck opera esclusivamente sul dispositivo dell'utente. I file non vengono mai inviati via rete, riducendo drasticamente il rischio di esposizione. Tuttavia, l'utente resta responsabile della sicurezza del proprio dispositivo.

6. Limiti del servizio

FileCheck fornisce analisi strutturali e indicazioni di affidabilità, ma non sostituisce software antivirus, strumenti forensi certificati o consulenze legali. I risultati sono indicativi e non garantiscono l'assenza totale di minacce.

7. Aggiornamenti

La presente policy può essere aggiornata per riflettere cambiamenti funzionali o normativi. Le modifiche saranno visibili in questa sezione.

8. Contatti

Per informazioni sulla privacy o sul trattamento locale dei dati, contatta il team FileCheck tramite i canali ufficiali indicati nella documentazione pubblica.
