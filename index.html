Zero-Knowledge Architecture

HWTRS opera interamente nel tuo browser. Nessun file o password lascia mai il tuo dispositivo. Non abbiamo server, database o sistemi di tracciamento.

  • ✓ PBKDF2 con 300.000 iterazioni per key derivation
  • ✓ Nessuna connessione di rete durante la cifratura/decifratura
