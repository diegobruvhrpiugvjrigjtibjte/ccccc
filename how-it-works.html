Come funziona HWTRS

Una spiegazione semplice, ma completa, del flusso di cifratura locale.

Panoramica

HWTRS è una web-app che cifra e decifra archivi direttamente nel browser. Questo significa che l’intero flusso si svolge sul tuo dispositivo: i file non vengono mai caricati su server esterni, non esistono account e non c’è alcuna infrastruttura centrale da violare. L’obiettivo è semplice: darti pieno controllo sui dati, riducendo la superficie d’attacco e mantenendo un’esperienza immediata.

Il formato .hwtrs è progettato per contenere più file in un singolo archivio, preservando nomi, dimensioni e tipi. La cifratura utilizza AES-256-GCM, uno standard moderno e sicuro, mentre la chiave viene derivata dalla tua password con PBKDF2 e 300.000 iterazioni. Questo rende gli attacchi a forza bruta più costosi e l’archivio più resistente.

1. Selezione dei file

Il primo passaggio consiste nella selezione dei file da proteggere. Puoi trascinare i documenti o selezionarli dal file system. HWTRS crea una lista ordinata con metadati minimi: nome, dimensione e tipo MIME. Questi dati servono esclusivamente per ricostruire i file in fase di apertura e non vengono mai trasmessi all’esterno.

La dimensione massima complessiva è di 150MB. Questa scelta tiene conto dei limiti tipici del browser, della RAM disponibile e delle performance complessive, mantenendo un buon equilibrio tra sicurezza e praticità.

2. Derivazione della chiave

La password non viene usata direttamente come chiave. HWTRS applica PBKDF2 con 300.000 iterazioni e un salt casuale per derivare una chiave AES-256-GCM. Questo processo aumenta drasticamente il costo computazionale di eventuali tentativi di decifrazione non autorizzata, rendendo la password più resistente anche se un attaccante ottiene il file cifrato.

Per questo motivo è importante scegliere una password lunga e robusta. Più è lunga, più la derivazione produce una chiave forte e difficile da attaccare.

3. Cifratura e creazione dell’archivio

Una volta derivata la chiave, i file vengono concatenati in un payload binario che include anche i metadati. L’intero blocco viene cifrato con AES-256-GCM, che garantisce sia la riservatezza sia l’integrità. Il risultato è un file .hwtrs che puoi salvare o condividere.

Il formato include un’intestazione con il magic header e la versione. Questo rende possibile verificare rapidamente se il file è valido e gestire la compatibilità futura.

4. Apertura e decifratura locale

Per aprire un archivio .hwtrs, carichi il file nel browser e inserisci la password. HWTRS deriva nuovamente la chiave, verifica l’integrità e ricostruisce i file originali. Tutto avviene in RAM: nessun dato viene inviato in rete.

Al termine puoi scaricare i file singolarmente o in un archivio ZIP. In qualsiasi momento puoi “pulire la RAM” per rimuovere i dati temporanei dal browser.

Perché questo flusso è affidabile

La combinazione di cifratura moderna, derivazione della chiave e assenza di server riduce il rischio di esposizione. Non esistono API, database o log che possano essere violati. L’unico elemento critico è la password, che rimane sotto il controllo dell’utente. Questo approccio è ideale per chi vuole privacy reale e un controllo diretto sui dati.

In sintesi, HWTRS funziona come un “contenitore” cifrato personale: semplice da usare, trasparente e coerente con il paradigma zero-knowledge. È una soluzione pratica per proteggere documenti personali, file aziendali o archivi sensibili da accessi non autorizzati.
